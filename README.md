# ASTERRA: Beyond Heaven — Book Website

A static website starter built with HTML, CSS, and a little JavaScript. No framework or build process is needed.

## Files
- `index.html` — leather book cover and opening interaction
- `library.html` — contents page with volumes and chapter list
- `chapters/letter-one.html` — sample chapter with Luna and Aster's margin notes
- `about.html` — introduces the two authorial voices
- `styles.css` — design and responsive styling
- `script.js` — open/close book interaction

## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Upload the extracted files and folders—not the ZIP itself.
4. Keep the `chapters` folder and its file in place.
5. In the repository, open **Settings → Pages**.
6. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
7. Wait for GitHub Pages to publish and open your website URL.

## Add a chapter
Copy `chapters/letter-one.html`, rename it, edit the text and title, then add its link to `library.html`. Keep the folder structure intact.

## Notes
The chapter currently contains sample placeholder prose. Replace it with your own manuscript before public release. The site has no database or user accounts. Google Fonts are loaded online, with fallback fonts if they are unavailable.
