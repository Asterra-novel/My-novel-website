# Asterra Stories — Website Starter

This is the first UI version of your novel website.

## Publish with GitHub Pages
1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html` from this folder to the repository's root (top level).
4. Commit the changes.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then save.
8. Wait a minute or two and open the website link shown in the Pages settings.
